Product Inventory Management API

It is a FastAPI-based REST API for managing products and inventory.

Technologies used:

Python,
FastAPI,
MySQL,
SQLAlchemy,
Pydantic,
PyMySQL,
Swagger UI

Main concepts covered:

CRUD operations,
Database connectivity,
API endpoints,
Request/response validation,
Filtering and searching,
Sorting and pagination,
Stock management,
Statistics,
Error handling,
Transactions,
Soft delete
